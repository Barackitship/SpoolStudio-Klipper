# Spool Studio 3.1.0

Spool Studio now supports native NFC/RFID tag links in Spoolman 0.27.0 and later, while keeping existing Paxx12 SpoolLink installations compatible.

- Native tag owners take priority over stale `card_uids` entries. UID scans work without an OpenSpool payload. Filament tags are identified without automatically choosing a spool.
- Compatibility mode writes native links and the legacy `card_uids` field. Older Spoolman servers retain the legacy workflow.
- New per-server **Native tags only** setting for users with compatible printer firmware.
- Settings include a migration preview. Copy links while retaining the legacy field, or explicitly clear successfully migrated entries. Invalid, duplicate and conflicting entries remain for review; native owners are not moved by migration.
- Manage and unlink tag links from the selected spool. Explicit UID linking can move a native spool tag after confirmation; ordinary saves report ownership conflicts.
- Fixed **New from selected** losing **Material modifier**, including PETG **2.0**. Duplicating also avoids reusing the original tag UID.
- Fixed the prerequisite message when the printer has no Paxx12 toolhead assignment command.

Keep compatibility mode enabled until your printer firmware supports native Spoolman tags. Clearing `card_uids` can break automatic detection in older firmware. Tag encoding is unchanged; OpenTag3D content support and external scanner subscriptions are separate features.

Build version: **3.1.0**, Android version code **24**.

Validation: 115 automated tests passed; Android Lint reports zero errors. Physical NFC / U1 testing remains outstanding.
