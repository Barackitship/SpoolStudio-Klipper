## Spool Studio v3.0.10

### Fixes

- Fixed the UID status field after reading an empty or non-OpenSpool NFC/RFID tag.
- The physical UID captured during the scan is now shown immediately in the spool status panel.
- A UID already stored on the selected Spoolman spool continues to take priority in the status display.

### Notes

- This fixes GitHub issue #8.
- The tag content is not changed by reading the UID.
- The captured UID remains available for the existing **Link scanned UID** workflow.
