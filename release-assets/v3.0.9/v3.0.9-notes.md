## Spool Studio v3.0.9

### Changes

- Updated the Paxx12 SpoolLink readiness logic for newer firmware versions.
- Removed the misleading **Assignment command** readiness check from Settings.
- Toolhead status now depends on the printer Spoolman/SpoolLink components instead of the incomplete Moonraker `gcode/help` command list.
- Manual toolhead assignment now tries the real Paxx12 assignment commands directly:
  - `SET_PRINT_FILAMENT_CONFIG ...`
  - fallback: `SET_SPOOL_ID ...`
- After a manual assignment, Spool Studio still verifies that the printer reports the expected spool ID.
- RFID write readiness no longer incorrectly depends on the hidden assignment command check.

### Why this changed

With recent Paxx12 firmware, the assignment command may no longer be listed in Moonraker `gcode/help`, even though manual toolhead assignment still works. Spool Studio now follows the actual firmware behavior instead of treating the missing help entry as a hard error.

### Notes

- Built for the Paxx12 SpoolLink workflow where the printer identifies spools by the physical tag UID stored in Spoolman.
- Tested against the current Paxx12 1.6.0 generation.
- If manual assignment fails, the app now reports a real write failure instead of asking for the old AFC Lite related setup.
